## What hiring managers actually scan (senior FE)

| Criterion | Why it matters | Arsenii | Ihor (before) | Ihor (after) |
|---|---|---|---|---|
| **6-second scan** | Recruiter decides in seconds | 2 pages, clean hierarchy | 4 pages, Soft Skills + Core Value first | ~2–3 pages, impact first |

| **Fluff tax** | Soft skills lists hurt seniors | None | Soft Skills + Core Value | Removed — demonstrated in experience |

## High-risk / high-reward bets (intentional)

1. **Kill Soft Skills & Core Value** — seniors show these in bullets; listing them reads junior.
2. **Lead with distinctive niche** — interactive builders / complex UI, not “another React senior”.
3. **Selected Achievements block** — copy Arsenii’s strongest format and beat it with your builder + product story.
4. **Hopme as shipped product** — founder signal Arsenii lacks; kept short so it doesn’t look like you left employment for a hobby.
5. **Full-stack ownership** — Rails APIs/migrations as delivery leverage, not “also know backend”.
6. **Professional AI line** — process language, not “Claude Opus / Sonnet / Grok” keyword stuffing.
7. **Compress early roles** — Halo / Asferro to 1 bullet each; free space for Strong SD / Svitla depth.

## What not to invent

Metrics kept only from your prior CV/LinkedIn (40% UX efficiency, ~30% load, 15% retention, 10k+ users, 20–25% engagement, 15–20% bug rate, ~10% velocity). If any number is soft, replace with a concrete technical outcome before sending to FAANG-style screens.
